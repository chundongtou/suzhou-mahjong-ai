# 🀄 苏州麻将 AI 军师

开打前打开即用的苏州麻将博弈分析助手：输入当前牌局（手牌/已打/碰杠），本地 Ollama 大模型实时推理，输出打牌决策。

> 规则引擎基于「微乐江苏麻将」苏州麻将玩法逆向整理：只能碰不能吃、对对胡为基本胡型、花牌(1/5/9+风)计分、滴零x2、豪七、百搭玩法等。

## ✨ 功能

- 🎴 **点选输入**：牌面选择器点几下就录入牌局，不用打字
- 📷 **截图识别**：粘贴牌桌截图，qwen2.5vl 视觉模型自动识别手牌/牌河并填入（可手动修正）
- 🧠 **AI 决策**：按固定四模块输出——我方手牌分析 / 别家胡牌推测 / 打牌决策 / 风险总结
- 📋 **一键复制**结果；规则与牌局自动保存在浏览器本地
- 📱 **局域网可用**：手机平板也能打开（同一WiFi下访问本机IP）

## 🚀 快速开始（Windows）

1. 安装 [Ollama](https://ollama.com/download) 并拉取模型：
   ```
   ollama pull qwen2.5vl:7b
   ollama pull qwen2.5vl:3b
   ```
   （7b 用于推理、3b 用于截图识别；只有 7b 也行）
2. 安装 Python 依赖：`pip install flask`（Python 3.8+）
3. 双击 **`start.bat`** → 浏览器自动打开 → 录入牌局 → 点「AI 分析决策」

## 🌐 GitHub Pages 直开（可选）

网页版: `https://chundongtou.github.io/suzhou-mahjong-ai/`

Pages 版前端会直连你本机的 Ollama（`127.0.0.1:11434`），所以仍需本机运行 Ollama（不需要启动 start.bat）。若浏览器拦截跨域请求，请改用本地 start.bat 方式。

## 🎮 使用流程

1. 打开页面 → 确认右上角「Ollama 已连接 ✓」
2. 「本局规则」面板选好玩法（苏州麻将/百搭、胡法、可选规则）
3. 录入牌局：
   - 方式一：点牌面选择器（先选"加入目标"：手牌/我已打/各家已打/碰杠）
   - 方式二：点「📷 截图识别」→ 粘贴截图(Ctrl+V) → 自动识别填入
4. 点「🧠 AI 分析决策」→ 等待推理 → 查看四模块决策
5. 每局结束点「🧹 清空」，规则会自动记忆不用重选

## 🛠 模型配置

页面顶部可切换推理/识别模型（自动探测本机已装模型）。推荐：
- 推理：`qwen2.5vl:7b`（聪明）或 `qwen2.5:7b`（更快）
- 识别：`qwen2.5vl:3b`（快）或 `qwen2.5vl:7b`（准）
